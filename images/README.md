# Images

Placeholder images used by `index.html`. Replace them with real ones and update the `src` in `index.html` if you change the file name or extension.

| File | Used for | Size |
| --- | --- | --- |
| `profile.svg` | Hero profile photo (e.g. replace with `profile.jpg`) | square, 400×400 or larger |
| `projects/meeting-analyzer.svg` | Meeting Analyzer screenshot | 16:9, e.g. 1600×900 |
| `projects/personal-automation.svg` | Personal Automation screenshot | 16:9 |
| `projects/project-api.svg` | Backend project screenshot | 16:9 |
| `projects/project-web.svg` | Web project screenshot | 16:9 |

If an image fails to load, `script.js` removes it and the fallback underneath shows (the "F" initial for the photo, the emoji for projects).

The CV for the hero's "Download CV" button is `files/fahim-cv.pdf` (also a placeholder).
